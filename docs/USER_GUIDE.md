# 烟火账安装与使用指南

## 安装

1. 将烟火账 Release APK（当前为 `yanhuozhang-v2.6.0-release.apk`）复制到手机；
2. 在 HyperOS 中允许当前文件管理器“安装未知应用”；
3. 打开 APK 并完成安装；
4. 以后升级直接安装同一签名的新 APK，不要先卸载，卸载会删除本机账本。

也可连接 ADB 安装：

```powershell
adb install -r yanhuozhang-v2.6.0-release.apk
```

安装包只支持 64 位 ARM 手机（`arm64-v8a`）。同目录的 `.sha256` 文件可用于核对安装包是否完整。

## 首次设置

首次启动会显示权限检查页：

1. 开启“烟火账微信支付识别”的通知访问；
2. 开启“烟火账微信支付页面识别”的无障碍服务；
3. 允许接收新短信；
4. 允许待确认通知；
5. 在小米安全中心允许烟火账自启动；
6. 将烟火账的电池策略设为“无限制”。

之后可随时在“设置 → 权限与后台运行”查看各项是否仍然开启，并跳转到对应的系统设置。

无障碍服务连接后，通知栏会常驻一条低优先级的“支付页面识别运行状态”通知。它让 HyperOS 不再在微信启动时冻结烟火账，避免漏记支付成功页；不想看到可以在系统通知设置里隐藏这个通知类别，但不要关闭无障碍服务。

应用不会读取历史短信。只有启用 DeepSeek 后，自动分类、月度分析和截图记账才会联网；截图记账只在你主动选择或分享截图时，把这张截图发给 DeepSeek。

## 页面操作

- 应用使用绿色种子色主题，不跟随系统壁纸改变配色；
- 底部导航中间的“＋”可从任意页面打开手动记账；
- 账单页可点击已有账单进行编辑，并使用账单卡片内的删除操作进行软删除；
- 待确认页用于处理自动识别中的歧义事件；
- 统计页显示对齐的六个月收支趋势和连续的本月分类圆环图，并可进入月度分析页；
- 设置页从上到下依次是：权限与后台运行、提醒（每日待确认汇总的时间）、应用锁（立即、1 分钟或 5 分钟后锁定）、自动分类（DeepSeek 与支付页截图识别）、分类管理（名称、emoji、颜色、排序、启用）、个人规则、备份与恢复。

如果 HyperOS 将无障碍或通知访问标记为受限设置，连接 USB 调试后执行：

```powershell
adb shell appops set com.yanhuozhang.offline ACCESS_RESTRICTED_SETTINGS allow
```

随后回到烟火账设置页，分别进入系统通知访问和无障碍设置开启对应服务。

## 自动记账规则

- 自动分类优先级依次为个人对象规则、本地高可信关键词、DeepSeek；
- 餐饮、火锅、自助餐、滴滴、打车、医院、药房、学校、超市等明确关键词会在本地分类；
- 本地无法判断时，仅在“设置 → 自动分类”启用 DeepSeek 并保存 API Key 后调用 DeepSeek；
- 可在同一设置区选择 V4.1 Flash 或 V4 Pro，以及思考或非思考模式；
- 思考模式会为模型预留更多输出 Token 和等待时间，通常也会产生更高的调用耗时；
- DeepSeek 只能从应用已有分类中选择；结果不可靠、网络异常或额度不足时保持未分类并提醒手动处理；
- 手动新增或编辑普通支出时，勾选“记住此交易对象”会新增或更新个人规则；
- “同时修改历史相同对象的未分类账单”只更新未分类记录，不覆盖已有分类；
- “微信支付／已支付￥14.80”会立即生成微信支出，再按上述规则分类；
- 微信支付成功页存在可见文字时，会优先生成或补全交易对象；
- 成功页的文字里读不到商家时，会对该页截图一次，在本机识别商家名并与金额核对，截图不上传；可在“设置 → 自动分类 → 支付页读不到商家时截图识别”关闭；
- 同一设置项下的“调试模式”会保存每次的截图和识别原文，用于排查识别不准；“裁剪区”调整截图中用于识别的上下范围，一般不需要改动；
- 发送微信红包时，应用会在“发红包”金额页临时记录金额；返回聊天页并检测到新增的己方“微信红包”卡片后，才生成红包待确认事件；
- 红包待确认事件默认按转出处理且不计入普通收支，确认时可再选择实际用途；
- 取消发送、超过 90 秒或聊天页没有新增红包卡片时，不会生成红包事件；
- 微信支付结果短信可单独生成支出，也可补充已有通知账单；
- 转账、退款、模板未知、方向不明确和同金额歧义进入待确认；
- 待确认事件在处理前不计入统计；
- 同一来源事件重放不会重复记账；
- 删除自动账单后会保留忽略指纹，避免相同事件重新导入。

## 截图记账

支付宝、抖音、美团、校园食堂等不会自动记账的支付，可以用截图记一笔：

- 打开“＋”记录一笔，点击“从截图识别”并选择截图；或在相册、截图预览里点“分享”，选择“截图记账”；
- 需要先在“设置 → 自动分类”启用 DeepSeek 并保存 API Key；
- 识别固定使用 DeepSeek Flash 并开启思考模式，不跟随设置里的模型和思考选项，可能需要几十秒，识别中可随时取消；
- 识别结果只会填进表单，核对后点“保存”才会入账；
- 截图里没写明交易对象时，会根据网址、页面标题等线索推测，并标注“推测”；推测的交易对象默认不勾选“记住此交易对象”；
- 截图里没有时间时使用当前时间并提示核对；支付宝、抖音等平台记为“其他”支付方式，平台名写在备注里；
- 已有金额和方向相同、时间相近的账单时，会提示“可能已经记过这笔”，只提示不拦截；
- 一张截图里有多笔交易（账单列表）时不会识别，请打开单笔详情页再截图；
- 应用锁设为“立即”时，从相册选完图返回会要求先解锁；解锁后会自动重新打开“记录一笔”并接上识别结果。

## 月度分析

- 统计页的“DeepSeek 月度分析”卡片可进入独立的月度分析页，按月份切换查看；
- 本地统计（净支出、最大单笔、商家消费金额和频率 TOP 10、高频小额候选、本地异常候选等）不联网，随时可看；
- 启用 DeepSeek 后，每月最后一天 23:30 自动生成结构化消费月报，也可点击“立即分析本月”手动生成或重试；
- 生成月报时会向 DeepSeek 发送当月全部消费与退款的时间、金额、商家、分类、支付方式和备注，以及本地统计结果；不发送收入、转账、原始通知或短信。

## 转账与退款

- 转账确认时分别选择转入/转出，以及是否计入普通收支；
- 退款可选择冲减退款当月，也可关联原消费并调整原消费月份；
- 关联原消费不会篡改退款实际发生时间。

## 备份

在“设置 → 备份与恢复”中导出 `.yhzbak` 文件。密码至少 6 个字符且无法找回。

恢复时会先验证密码、认证标签、数据版本和引用关系。只有全部通过后才替换本机数据；失败不会覆盖现有账本。

## 签名密钥

`yanhuozhang-release.jks` 和 `yanhuozhang-signing-credentials.txt` 用于以后发布覆盖升级包。二者应额外复制到安全位置，不要放在公开网盘或源码仓库。
