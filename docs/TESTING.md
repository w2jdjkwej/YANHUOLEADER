# 烟火账 V1 真机验收清单

## 安装与数据

- [ ] 正式 APK 可在 Android 16 / HyperOS 3 安装；
- [ ] 首次设置页能打开六个正确的权限或系统设置入口；
- [ ] 设置页能正确显示“微信支付页面读取”的启用状态；
- [ ] 覆盖安装同一签名 APK 后账单和设置保留；
- [ ] 手动备份、清空测试数据后恢复，账单、事件、分类和规则一致；
- [ ] 错误密码和损坏备份不会覆盖现有数据。

## 微信通知

- [ ] 支付一笔普通小额交易，系统通知出现后 10 秒内生成一条未分类支出；
- [ ] 应用在后台和锁屏状态下仍能采集；
- [ ] 重启手机后再次支付仍能采集；
- [ ] 关闭通知访问后，设置页能显示未授权状态；
- [ ] 正常自动支出不额外发送烟火账通知。

## 微信支付成功页

- [ ] 页面显示“支付成功、吉林大学、￥10.00、完成”后，10 秒内生成交易对象为“吉林大学”的 10.00 元支出；
- [ ] 以后打开不含“完成”按钮的历史交易详情不会被识别为新支付；
- [ ] 页面事件与通知描述同一交易时只保留一条账单；
- [ ] 通知先入账时，成功页随后能补全空白交易对象；
- [ ] 已有非空交易对象不被不同页面文字覆盖；
- [ ] 成功页内容反复刷新不会重复入账；
- [ ] 连续两笔相同商户、相同金额的真实支付均能保留；

## 微信红包

- [ ] 打开“发红包”金额页并输入金额后取消，待确认页不会新增事件。
- [ ] 输入金额并成功发送，微信自动返回聊天页且出现新增的己方“微信红包”卡片后，10 秒内生成一条红包待确认事件。
- [ ] 红包待确认事件金额与发送金额一致，默认是转出方向且不计入普通收支。
- [ ] 聊天页原有红包卡片、领取提示或重复刷新不会重复生成事件。
- [ ] 金额页停留超过 90 秒、切换聊天对象或没有出现新增红包卡片时，不会误生成事件。
- [ ] 原有“待某人确认收款”转账识别行为保持不变。

## 短信与合并

- [ ] 网络波动产生微信支付结果短信时能识别金额和交易时间；
- [ ] 通知和短信描述同一交易时只有一条账单，详情保留两个事件；
- [ ] 普通银行短信不会直接计入收支，而是进入待确认；
- [ ] 普通个人短信不会产生交易事件。

## 去重和歧义

- [ ] 同一通知回放两次只生成一条账单；
- [ ] 连续两笔同金额、同来源且时间接近时进入待确认；
- [ ] 软删除自动账单后，同一事件重放不会重新入账；
- [ ] 待确认事件可确认、合并或忽略。

## 统计

- [ ] 本月收入、支出和结余与账单明细一致；
- [ ] 资金流转默认不混入普通收支；
- [ ] 退款可冲减退款当月或原消费月份；
- [ ] 分类排行、分类占比和六个月趋势口径一致。
- [ ] 六个月趋势显示每个月收入与支出的具体金额，左右滑动时月份和金额保持对应。
- [ ] 收支柱形底部与月份文字保留间距，不重叠；金额较长时不遮挡相邻月份。
- [ ] 趋势标题、图表、分类标题和饼图按顺序排列且互不遮挡；
- [ ] 分类占比图为实心正圆，不显示为椭圆或圆环；

## 界面

- [ ] 首页、账单、待确认、统计和设置页均以蓝白冷色为主；
- [ ] 更换系统壁纸后，烟火账配色不会变为系统动态色；
- [ ] “＋”手动记账按钮只在首页显示；
- [ ] 桌面图标显示用户提供的卡通人物图片，圆形和系统自适应裁剪下人物完整。
