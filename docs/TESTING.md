# 烟火账真机验收清单（v2.6.0）

主要验收设备：Android 16、HyperOS 3、机型代码 `2509FPN0BC`。

## 安装与数据

- [ ] 正式 APK 可在 Android 16 / HyperOS 3 安装；
- [ ] 覆盖安装同一签名的新版本后，账单、分类、规则和设置（含 DeepSeek API Key）保留；
- [ ] 首次设置页能打开六个正确的权限或系统设置入口；
- [ ] “设置 → 权限与后台运行”能正确显示通知访问、支付页面读取、短信、通知和自启动的状态；
- [ ] 手动备份、清空测试数据后恢复，账单、事件、分类和规则一致；
- [ ] 错误密码和损坏备份不会覆盖现有数据。

## 微信通知

- [ ] 支付一笔普通小额交易，系统通知出现后 10 秒内生成一条支出，并按个人规则、本地关键词或 DeepSeek 分类；
- [ ] 应用在后台和锁屏状态下仍能采集；
- [ ] 重启手机后再次支付仍能采集；
- [ ] 关闭通知访问后，设置页能显示未授权状态；
- [ ] 正常自动支出不额外发送烟火账通知。

## 微信支付成功页

- [ ] 页面显示“支付成功、吉林大学、￥10.00、完成”后，10 秒内生成交易对象为“吉林大学”的 10.00 元支出；
- [ ] 微信 Lite 支付成功页（文字在 `contentDescription` 中）同样能读取商户和金额；
- [ ] 无障碍服务开启后，通知栏出现低优先级的“支付页面识别运行状态”常驻通知；
- [ ] 冷启动微信后立即支付，`adb shell dumpsys greezer` 显示烟火账未被冻结，支付页不漏读；
- [ ] 以后打开不含“完成”按钮的历史交易详情不会被识别为新支付；
- [ ] 页面事件与通知描述同一交易时只保留一条账单；
- [ ] 通知先入账时，成功页随后能补全空白交易对象；
- [ ] 已有非空交易对象不被不同页面文字覆盖；
- [ ] 成功页内容反复刷新不会重复入账；
- [ ] 连续两笔相同商户、相同金额的真实支付均能保留。

## 支付页商家截图识别

- [ ] 成功页文字里读不到商家时，只截图一次，并在本机识别出商家名补全账单；
- [ ] 截图识别出的金额与账单不一致或找不到商家时，不猜测商家，按“商家待确认”处理；
- [ ] 关闭“支付页读不到商家时截图识别”后不再截图；
- [ ] 开启调试模式后，应用专属目录保存截图和识别日志，“清除调试文件”能全部删除。

## 微信红包

- [ ] 打开“发红包”金额页并输入金额后取消，待确认页不会新增事件；
- [ ] 输入金额并成功发送，微信自动返回聊天页且出现新增的己方“微信红包”卡片后，10 秒内生成一条红包待确认事件；
- [ ] 红包待确认事件金额与发送金额一致，默认是转出方向且不计入普通收支；
- [ ] 聊天页原有红包卡片、领取提示或重复刷新不会重复生成事件；
- [ ] 金额页停留超过 90 秒、切换聊天对象或没有出现新增红包卡片时，不会误生成事件；
- [ ] 原有“待某人确认收款”转账识别行为保持不变。

## 短信与合并

- [ ] 网络波动产生微信支付结果短信时能识别金额和交易时间；
- [ ] 通知和短信描述同一交易时只有一条账单，详情保留两个事件；
- [ ] 普通银行短信不会直接计入收支，而是进入待确认；
- [ ] 普通个人短信不会产生交易事件。

## 去重和歧义

- [ ] 同一通知回放两次只生成一条账单；
- [ ] 连续两笔同金额、同来源且时间接近时进入待确认；
- [ ] 软删除自动账单后，同一事件重放不会重新入账；
- [ ] 待确认事件可确认、合并或忽略。

## 自动分类

- [ ] 未启用 DeepSeek 时，本地无法分类的账单保持“未分类”并发送待分类提醒；
- [ ] 启用 DeepSeek 后，本地无法分类的账单能自动归入已有分类，提醒随之撤回；
- [ ] API Key 错误、断网或额度不足时保持“未分类”并提醒手动处理；
- [ ] 手动分类并勾选“记住此交易对象”后，同一对象的新账单自动归入该分类；
- [ ] “同时修改历史相同对象的未分类账单”只改未分类记录。

## 截图记账（v2.6.0 新增）

- [ ] 未启用 DeepSeek 时，“从截图识别”按钮不可用并提示去设置；
- [ ] 在“记录一笔”中点“从截图识别”选择支付截图，识别中显示进度和已用秒数，可以取消；
- [ ] 食堂订单截图（如订单金额 16.65、下单时间 2026/10/11 11:29）能填入正确的金额和时间，交易对象标注“推测”并显示依据；
- [ ] 支付宝、抖音、美团等不同 App 的支付截图都能识别出金额和时间，渠道为“其他”，备注含平台名；
- [ ] 截图里没有时间时使用当前时间，并在时间下方提示核对；
- [ ] 推测出的交易对象默认不勾选“记住此交易对象”；
- [ ] 与已有账单金额、方向相同且时间相近时显示“可能已经记过这笔”，仍可保存；
- [ ] 账单列表（多笔）截图、聊天截图等非交易图片提示识别未完成，表单保持可手动填写；
- [ ] 在相册或截图预览中分享到“截图记账”，应用打开“记录一笔”并自动开始识别；应用锁开启时先解锁再识别；
- [ ] 应用锁设为“立即”时，从相册选图返回并解锁后，“记录一笔”自动重新打开并接上识别结果；
- [ ] 识别结果只回填表单，不点“保存”不会入账。

## 统计与月度分析

- [ ] 本月收入、支出和结余与账单明细一致；
- [ ] 资金流转默认不混入普通收支；
- [ ] 退款可冲减退款当月或原消费月份；
- [ ] 分类排行、分类圆环图和六个月趋势口径一致；
- [ ] 六个月趋势显示每个月收入与支出的具体金额，左右滑动时月份和金额保持对应；
- [ ] 收支柱形底部与月份文字保留间距，不重叠；金额较长时不遮挡相邻月份；
- [ ] 月度分析页可切换月份，本地统计在未启用 DeepSeek 时也能显示；
- [ ] 启用 DeepSeek 后点“立即分析本月”能生成结构化月报；每月最后一天 23:30 自动生成。

## 提醒与应用锁

- [ ] 每日待确认汇总按设置的时间提醒；
- [ ] 应用锁的“立即、1 分钟、5 分钟”三档按离开应用的时长生效，支持生物识别和设备凭据。

## 界面

- [ ] 各页面使用绿色种子色主题，更换系统壁纸后配色不会变为系统动态色；
- [ ] 深色模式下各页面文字清晰可读；
- [ ] 底部导航中间的“＋”在任意页面都能打开“记录一笔”；
- [ ] 桌面图标显示用户提供的卡通人物图片，圆形和系统自适应裁剪下人物完整。
